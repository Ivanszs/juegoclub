# JuegoClub

Trabajo práctico integrador para la materia Desarrollo de sistemas Orientado a Objetos.
Es un sistema sencillo con su interfaz por consola hecho en Python y MySQL para gestionar un ficticio club de juegos de mesa.

## Cómo correr el programa

En la carpeta del proyecto, escribir en la consola:

```bash
python pl/app.py
```
